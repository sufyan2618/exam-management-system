# Verity interface direction

## Identity assets

- Dark wordmark: `public/verity-logo-dark.svg`
- Light wordmark: `public/verity-logo-light.svg`
- Mark and favicon: `public/favicon.svg`
- Keep the supplied Verity wordmark and checkmark unchanged. The warm red in the mark is an existing identity color.

## Interface system

- Canvas: warm mineral ivory (`#f5f3ee`); raised surfaces: soft white (`#fffefa`).
- Main text: deep plum ink (`#211c24`); supporting text: muted graphite.
- Action color: Verity wine (`#7c2947`), with a restrained pale rose tint for selected states.
- Typography: Newsreader for expressive page headings; DM Sans for navigation, controls, and reading text.
- Layout: dark plum role navigation, quiet sticky workspace header, centered content measure, and compact data tables.
- Components: subtle borders, small consistent radii, minimal elevation, clear keyboard focus, and short state feedback.
- Candidate exam screens keep the same tokens with less surrounding chrome and strong reading contrast.

## Content and behavior

Preserve the existing route tree, navigation labels, auth forms and validation, role permissions, exam submission behavior, real API data, and accessibility affordances. Do not introduce sample stats or fabricated activity.
